# post-kun

自作アプリ(ローカルの Web API など)に GET / POST などの HTTP リクエストを送って、レスポンスを確認する Windows 用の小さなツールです。
パラメータ・ヘッダー・ボディはすべて表で入力し、クエリ文字列や JSON はアプリが組み立てます。

## 画面

- **左**: 保存したリクエストの一覧(名前順)。クリックで開きます。右クリックで「複製」「削除」
- **右上**: リクエストの編集
  - 名前 / メソッド / URL / 送信
  - タブ: **パラメータ**(GET のクエリ)・**ヘッダー**・**ボディ**
  - 一番下に、実際に送る URL(送信URL)が表示されます
- **右下**: レスポンス(ステータス・時間・サイズ、本文 / ヘッダー)

## 使い方

1. 「新規」で名前・メソッド・URL を入力する(`localhost:3000/api/users` のように `http://` は省略可)
2. URL に `?` は書けません。クエリは「パラメータ」タブの表に書きます
   - `?a=1&b=2` 付きの URL を貼り付けると、自動でパラメータの表へ移ります
3. 必要ならヘッダーを表に書く(`Content-Type` はボディの形式に合わせて自動で付きます)
4. ボディを作る(下記)
5. 「送信」または **Ctrl+Enter**
6. 「保存」または **Ctrl+S** で左の一覧に保存。未保存の変更があるときは「● 未保存」と表示され、切り替え・終了時に保存するか確認します

### ボディ(JSON)の作り方

「形式」で **JSON 連想配列{}** / **JSON 配列[]** / **フォーム** を選び、表に入力します。右側に送信される JSON がその場で表示されます。

| 列 | 内容 |
|---|---|
| 有効 | チェックを外すと送りません |
| キー | プロパティ名(配列の中では `[0]` `[1]` … と表示され、入力不要) |
| 型 | 文字列 / 数値 / 真偽値 / null / **連想配列{}** / **配列[]** |
| 値 | 値(連想配列・配列は中の件数を表示) |

- **＋ 行を追加**(Insert): 選択中の行の下に同じ階層の行を追加
- **＋ 子を追加**: 選択中の連想配列 / 配列の中に行を追加(何階層でも入れ子にできます)
- **↑ / ↓**(Alt+↑ / Alt+↓): 同じ階層の中で並べ替え
- **削除**(Ctrl+Delete): 行を削除(子も一緒に消えます)
- **JSON から取り込み**: 既存の JSON を貼り付けると、表に展開します
- 数値として読めない値などがあると、プレビューに ⚠ で場所と理由が表示され、送信されません

例: 次の表から

```
name      文字列      山田太郎
tags      配列[]      [ 2 件 ]
  [0]     文字列      admin
  [1]     連想配列{}  { 1 件 }
    id    数値        7
```

次の JSON が作られます。

```json
{ "name": "山田太郎", "tags": [ "admin", { "id": 7 } ] }
```

### キー操作

| 操作 | キー |
|---|---|
| 送信 / 送信中はキャンセル | Ctrl+Enter |
| 保存 | Ctrl+S |
| 新規 | Ctrl+N |
| URL 欄へ移動 | Ctrl+L |

サーバが起動していない、タイムアウトした(30秒)などの場合は、理由がレスポンス欄に表示されます。
すでに起動している状態でもう一度起動すると、開いているウィンドウが前面に出ます。

## 保存場所

`%APPDATA%\post-kun\` に保存されます。

- `requests.json`: 保存したリクエスト
- `settings.json`: ウィンドウの位置・大きさなど

読み込めない場合は `*.bak` に退避してから空の状態で起動します。

## ビルドと起動

```
.\restart.bat
```

`publish\PostKun\PostKun.exe` が作られて起動します。以降はこの exe を直接起動できます。

開発時のビルド・テストの手順は [AGENTS.md](AGENTS.md) を参照してください。
